# Kids Learning Mathematics

This package separates the mathematics classroom into three clear categories:

- Elementary — beginner lessons from `New update math(1).html`
- T U — Tens & Units from `Tens and units(2).html`
- H T U — Hundreds, Tens & Units from `Tens and units(2).html`

The original teaching engines, speech, checkpoints/practice, progress, handwriting/board features and source lesson content are retained inside the standalone topic files.

Open `index.html` to choose a classroom. For GitHub Pages, upload the whole folder structure and enable Pages from the repository settings.
