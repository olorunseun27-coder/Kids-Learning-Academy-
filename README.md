# Kids Learning Maths

## Folder structure

- `index.html` — main Mathematics container
- `T-U/` — Tens & Units classrooms
- `H-T-U/` — Hundreds, Tens & Units classrooms

Each classroom is a standalone HTML file.

## GitHub Pages

After uploading this folder to a GitHub repository, enable GitHub Pages for the repository.
The `index.html` file is the main entry point.

New standalone topic files can be added inside the appropriate folder. The main launcher must be updated unless an automatic topic-registration system is added.
