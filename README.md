# Kids Learning Academy — Mathematics Container v1

This package adds a Firebase-backed parent/child container around the existing Mathematics classrooms. Existing classroom files are copied rather than rewritten.

Included: Parent registration/login, child profiles, class selection, Elementary/T U/H T U launcher, and basic cloud session tracking under parents/{parentUid}/children/{childId}/progress/session.

The deeper mapping of each existing lesson engine’s internal quiz/progress values into the cloud is intentionally left for the next integration phase, so the existing lesson functionality is not silently changed.
